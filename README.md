# BLACKLINE

Сайт вымышленного барбершопа в Киеве, сделанный для портфолио. Хотелось передать атмосферу небольшого премиального места: крупная типографика, спокойные тёмные цвета, фотографии и минимум лишнего интерфейса. Весь текст на сайте — на украинском.

## Как запустить

Нужен Node.js 20.9 или новее. Откройте терминал в папке проекта и выполните:

```bash
npm install
npm run dev
```

Сайт откроется по адресу [localhost:3000](http://localhost:3000). Если пользуетесь pnpm, в репозитории есть lock-файл: `pnpm install --frozen-lockfile` установит зафиксированные версии зависимостей.

Для проверки типов и сборки:

```bash
npm run typecheck
npm run build
npm start
```

Сборка создаёт папку `out` — готовый статический сайт, который можно разместить на статическом хостинге. `npm start` запускает локальный просмотр этой сборки. Перед сборкой остановите сервер разработки, чтобы два процесса Next.js не использовали `.next` одновременно.

## Что внутри

Next.js с App Router, TypeScript, Tailwind CSS, Framer Motion и Lucide React. Основное оформление находится в обычном CSS: так проще поддерживать нестандартную сетку и отступы.

- `app/` — страница, стили, метаданные и страница 404.
- `components/` — разделы сайта, навигация и форма записи.
- `lib/data.ts` — услуги, цены, мастера и ссылки на фотографии.
- `public/icon.svg` — иконка сайта.

Цены и информацию о мастерах удобнее всего менять в `lib/data.ts`. Контакты и часы работы находятся в `components/Contact.tsx`, а правила доступного времени — в `components/Booking.tsx`. При изменении графика нужно обновить оба места.

## Как работает запись

Нажатие на услугу или ссылку «До майстра» переносит посетителя к форме и подставляет выбранный вариант. Даты доступны на 60 дней вперёд. Воскресенье — выходной; в субботу рабочий день короче. Время учитывает длительность услуги и часовой пояс Киева.

Форма проверяет обязательные поля, телефон и электронную почту, затем показывает подтверждение. Это демонстрация: сервера и настоящего бронирования нет, введённые данные никуда не отправляются и не сохраняются после перезагрузки страницы.

Для реального барбершопа понадобится подключить систему записи, заменить вымышленные контакты, отзывы и профили мастеров. Ссылки Instagram пока ведут на главную страницу сервиса.

## Несколько деталей

Меню и форма доступны с клавиатуры, у полей есть подписи и сообщения об ошибках. Анимации учитывают настройку уменьшения движения. Метаданные и страница 404 тоже на украинском.

Файл `.openai/hosting.json` относится к размещению через Sites и не нужен для обычного локального запуска.
